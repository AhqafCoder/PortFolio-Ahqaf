# AHQAF_ALI.DEV — v2 "REVAMP"

Personal portfolio of **Ahqaf Ali** — full-stack developer & R&D engineer.
Dark "engineering workbench" theme with a Minecraft + robotics edge.

## Stack

- **Next.js 15** (App Router) + TypeScript
- **Tailwind CSS v4**
- **Lenis** — smooth scrolling (nav XP bar = scroll progress)
- **Framer Motion** — reveals, counters, toasts
- Zero image assets — all icons are hand-coded 16×16 pixel-art SVGs

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```
